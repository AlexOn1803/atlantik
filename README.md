# Atlantic Обігрівач

Android-застосунок для керування конвектором **Atlantic ALTIS ECO BOOST CHG-BD1/Wi‑Fi** (і іншими Wi‑Fi приладами Atlantic) через хмару Cozytouch — без офіційного застосунку.

## Що вміє

- **Керування:** увімкнути/вимкнути, бажана температура (±, повзунок, швидкі кнопки 7/16/19/21/23°), Boost, Еко, виявлення відкритого вікна, датчик присутності, випередження розкладу, «знайти прилад».
- **Тижнева програма:** перегляд тижня кольоровою смугою, редагування дня (до 10 інтервалів), копіювання на будні/вихідні/всі дні, тимчасова зміна температури і повернення до програми.
- **Відсутність:** «Поїхати на N днів» / «Я вдома».
- **Споживання:** лічильники приладу і добова статистика з хмари (графік за 30 днів).
- **Усі параметри:** кожне значення, яке прилад повідомляє, згруповане й підписане українською. Змінювані — з олівцем ✎; для невідомих є ручний запис з попередженням.
- **Діагностика:** кнопка «Поділитися» — текстовий список усіх значень приладу.

Показується лише те, що реально повідомляє саме твій прилад, тож набір перемикачів може відрізнятися.

## Важливо

1. **Перше підключення до Wi‑Fi** робиться один раз через офіційний Cozytouch («+» → Радіатор → Wi‑Fi Connected heater → BD0). Цей крок — закритий протокол Atlantic. Після того як прилад з'явився в акаунті, усе інше можна робити тут.
2. Це **неофіційний API** (той самий, що в інтеграціях Home Assistant `gduteil/cozytouch` і Homey `homey-cozytouch`). Atlantic може його змінити.
3. Хмара обмежує частоту запитів, тому застосунок оновлює дані раз на хвилину (кнопка ⟳ — вручну).
4. Пароль зберігається тільки на телефоні, зашифрований ключем Android Keystore. Запити йдуть лише на `apis.groupe-atlantic.com`.

## Як отримати APK

### Варіант А — GitHub Actions (без Android Studio)
1. Створи репозиторій на GitHub і завантаж туди вміст цієї папки.
2. Відкрий вкладку **Actions** → workflow **Build APK** запуститься сам (або натисни *Run workflow*).
3. Через ~5 хв у запуску внизу буде артефакт **AtlanticHeater-apk** — там `app-release.apk`. Встанови його на телефон (дозволь встановлення з невідомих джерел).

### Варіант Б — Android Studio
Відкрий папку як проєкт (Ladybug 2024.2+ або новіше), дочекайся синхронізації Gradle, *Run ▶*.

## Структура

```
app/src/main/java/ua/madeisy/atlantic/
  core/        — API Cozytouch, JSON, каталог параметрів, програма, логіка обігрівача (чистий Kotlin, з тестом)
  data/        — шифроване збереження логіна
  ui/          — екрани Compose: вхід, пристрої, керування, розклад, споживання, усі параметри
app/src/test/  — тест ядра проти фейкового сервера Cozytouch
```

## Якщо щось не працює

Надішли текст із кнопки **Діагностика** (вкладка «Усі параметри»). У ньому номери параметрів і значення твого приладу — по ньому можна точно підлаштувати назви і перемикачі під ALTIS.
